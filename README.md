# WholesaleStoreSimulation

Моделирование работы оптового магазина с помощью дискретно-событийной симуляции. Программа выполняет одиночный прогон модели, серии репликаций и дополнительные исследования устойчивости, переходных процессов, непрерывного прогона и чувствительности параметров. Для анализа результатов автоматически создаются HTML-отчёты.

## Возможности
- **Одиночная симуляция**: собирает основные метрики (обслуженные клиенты, средняя длина очереди, время ожидания и т.д.).
- **Серии репликаций**: агрегирует средние значения и стандартные отклонения для ключевых откликов.
- **Тесты хи-квадрат (1.1)**: проверяют гипотезу о нормальности распределения каждого отклика и визуализируют гистограммы.
- **Доверительные интервалы (1.2)**, **анализ сходимости (1.3)**, **анализ переходного периода (1.4)**, **непрерывный прогон (1.5)** и **чувствительность параметров (1.6)** с отдельными отчётами.

## Требования
- .NET 8.0 SDK или выше.

## Как запустить
1. Установите .NET 8 SDK.
2. В корне репозитория выполните сборку и тесты (опционально):
   ```bash
   dotnet build
   dotnet test
   ```
3. Запустите симуляцию:
   ```bash
   dotnet run --project WholesaleStoreSimulation/WholesaleStoreSimulation.csproj
   ```
4. После завершения работы программы в каталоге `WholesaleStoreSimulation/bin/<Configuration>/<TargetFramework>/` появятся отчёты:
   - `simulation_results.html` — основной отчёт с результатами симуляции и тестов хи-квадрат.
   - `confidence_intervals.html`, `convergence_report.html`, `transient_analysis_report.html`, отчёт по непрерывному прогону и чувствительности.

## Как это работает
- Файл `WholesaleStoreSimulation/WholesaleStoreSimulation.cs` содержит саму дискретно-событийную модель магазина и вспомогательные классы (клерки, клиенты, события).
- В `Program.cs` описан сценарий запуска: одиночный прогон, серия репликаций и последовательные анализы (хи-квадрат, доверительные интервалы и т.д.).
- Модули `ChiSquaredTest`, `ConfidenceIntervalAnalyzer`, `ConvergenceAnalyzer`, `TransientAnalysis`, `ContinuousRunAnalysis` и `SensitivityAnalysis` отвечают за конкретные этапы статистической верификации.
- Генераторы отчётов (`ChartGenerator`, `ConfidenceIntervalChartGenerator`, `ConvergenceChartGenerator`, `ContinuousRunChartGenerator`, `SensitivityChartGenerator`) создают HTML-файлы с графиками с использованием Chart.js и ScottPlot.

## Советы
- Изменяйте параметры симуляции через `SimulatorConfig` в `Program.cs`, либо создайте собственную конфигурацию перед запуском.
- Для ускорения тестов хи-квадрат уменьшите количество репликаций в `RunChiSquaredTests`.
- HTML-отчёты можно открыть в любом современном браузере.
